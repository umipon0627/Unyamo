# Unyam デザインシステム（ポップ・カジュアル）— 全エージェント共通の単一ソース

Figma: https://www.figma.com/design/yWDjZadTsUELcEI8dSe6Lo （html.to.design インポート由来。**変数は自動抽出でノイズが多いためスクショが正**）
参照スクショ: `docs/design-ref/01-onboarding.png` `02-lobby-waiting.png` `03-game-mobile.png` `04-desktop.png`

## コンセプト
温かいクリーム基調 + 親しみのある丸ゴシック + 多色アクセント。ゲーム卓のみ深緑フェルト。
「上品なポップ」= 原色ギラギラではなく、温かく軽快で楽しい。

## 絶対に壊さない契約（UI 以外触らない）
- `src/hooks/useGameState.ts` / `useWebSocket.ts` の **公開シグネチャ・戻り値キー名** 不変
- `party/messages.ts` の Zod スキーマ、`src/game-logic/*` 純粋関数 不変
- `availableActions` 値・`phase` の意味論・`players.length` 分岐ロジック 不変
- 変えてよいのは JSX 構造 / className / framer-motion / 画像 / globals.css / layout.tsx / フォント のみ
- 各画面の **操作要素・情報要素は現状と同じものを全て残す**（ボタンの意味・onClick 配線は保持、見た目だけ刷新）
- 回帰ゲート: 各ステップ後 `npm run type-check`(0) / `npm run test`(118緑) / `npm run lint`(新規エラー0) / Playwright E2E

## フォント（next/font/google）
- 見出し/ロゴ/ボタン: **M PLUS Rounded 1c**（weights 500,700,800）→ CSS 変数 `--font-heading`
- 本文/UI: **Inter**（既存維持、400,500,600,700）→ `--font-sans`
- 等幅（コード/ID表示）: **JetBrains Mono**（任意）→ `--font-mono`
- layout.tsx で両フォントを読み込み body に変数付与。`font-heading` ユーティリティを見出しに適用

## 形状・影・モーション
- 角丸: `--radius` 基底 **1rem(16px)**。カード/パネル ~20–24px、ボタン/バッジ **pill(9999)**、入力 ~14px
- ボーダー: 主要カードは太め 1.5–2px の温かい枠（`border`色）
- 影: 柔らかく暖色寄り `0 6px 20px -6px rgba(40,30,20,.18)`、押下で軽く沈む
- モーション(framer-motion): 弾む spring（`stiffness ~260, damping ~20`）、hover/tap で軽いスケール。手札の扇形・選択浮上は既存挙動を維持しつつイージングをポップに

## 画面別メモ（スクショ準拠）
1. **ランディング**: クリーム背景中央にトランプ束イラスト→「Unyam」丸ゴシック大見出し、サブ「CARD GAME」、主CTA「はじめる」(濃緑/pill)、下に「ルールを見る」テキストリンク。右上 JP/EN
2. **認証**: ロゴ→見出し「アカウントを連携してはじめましょう」→Googleボタン(白地/枠)→GitHubボタン(白地/枠)→区切り→「ゲストで開始」テキスト。下部に利用規約/プライバシー極小注記
3. **モード選択**: 見出し「あそびかたを選ぼう」→大カード2枚: 緑「オンライン対戦」(おすすめバッジ)、ネイビー「CPU対戦」→補助「ルールおさらい」行。下部タブバー(プレイ/CPU/戦績/プロフ)
4. **CPU設定**: 「人数」**1–3** ピル選択(選択=濃。※ゲームサーバー契約 max=3。4は不可)、「難易度」EASY/HARD トグル(選択=緑塗り)、「対戦相手プレビュー」リスト、最下部「対戦スタート」固定ボタン(本体は被り防止 pb-40)
5. **ロビー**: 「ロビー」見出し+件数、検索/再読込、ルーム行カード(左色帯=状態, ホスト名/難易度/人数/参加ボタン or 満員)、右上に作成
6. **作成ダイアログ/PWパスワード**: 中央モーダル(大角丸/白面/暗幕)、ルーム名入力、色選択チップ、公開/非公開、パスワード入力(※実システムは bcrypt の4–20文字フリーテキスト。スクショのPIN風4桁ボックスは**不採用**＝既存セキュリティ/検証を壊さない)
7. **待機ルーム**: ルーム名+ID、人数バッジ、参加者リスト(アバター/名前/YOU/HOSTタグ/READY|WAIT)、ホストのみ開始ボタン(※スクショのチャットは WebSocket protocol に存在しないため**不採用**＝新機能/契約変更はしない)
8. **ゲーム画面(最重要)**: 深緑フェルト。**上部ヘッダ**: 戻る/「R 3/12」ラウンドピル/山札残バッジ(🌐数)/ハート数/⚙。**相手プレイヤー**: 横並びチップ(色丸イニシャル+名前+「N枚」、伏せ札サムネ)。**ターンバナー**: 「あなたのターン 捨てるカードを選んでください」(白パネル赤丸 or 相手番表示)。**中央**: 山札(「山札26」)+捨札(「捨て札」)を白カードで並置。**下部アクション**: 赤「捨てる(選択したN枚)」/ ティール「引く」(フェーズで活性=既存条件) / 金outline「Unyam!」。**手札**: 「YOUR HAND·7」ラベル+下部に扇形(選択で浮上)。宣言時 全画面金フラッシュ。状態(自分/相手番・捨/引フェーズ)で見た目変化。**ダーク版あり**(07-dark: 同レイアウトで暗フェルト)
9. **リザルト**: creamヘッダ「リザルト GAME #xxxx」+戻る/共有。中央に**金枠丸の勝者アバター(猫シルエット)**+「Winner — 名前」金大見出し+「ウニャム宣言で勝利しました」。**順位リスト**: 各行=順位メダル/色丸アバター/名前+YOU・HOSTタグ/「残り手札N枚」or「ウニャム宣言・手札0」/ 得点(+140緑・-40赤、font-heading太)。**NEXT LEVEL**カード: 「Lv.12→Lv.13」+XPプログレスバー+「+140 XP・あと60 XPでレベルアップ」。固定フッタ「退室」/「もう一度」(ホストのみ活性=既存ホスト判定)。**ダーク版あり**(08-dark)
10. **プロフィール/戦績**: creamヘッダ「プロフィール STATS·HISTORY」+戻る/⚙。**プロフィールカード**: 大色丸アバター+名前+「@id・Lv.12・連勝4」+バッジ(🏆SILVER, 24 GAMES)。**3スタットカード**横並び: 「14 WIN」「10 LOSE」「58% 勝率」(数字font-heading大、色帯=緑/赤/金)。**スコア推移カード**: 「スコア推移 LAST 10」+折れ線(teal)+合計+320。**HISTORYリスト**: 各行=順位メダル/「1位/4人」/「2時間前・オンライン」/得点(+120緑/-20赤)。下部タブバー固定。※既存の戦績データAPI/集計ロジックは不変、表示のみ刷新
11. **共通**: ヘッダー(ロゴ+ユーザー)、フッター/下部タブバー(プレイ/ロビー/戦績/プロフ。戦績・プロフ画面が揃う **Step4 で実装**)、ライト/ダーク切替トグル

> 注: スクショのランディング右上「JP/EN」は i18n 基盤が無いため**不採用**（非機能の飾りトグルは付けない）。
